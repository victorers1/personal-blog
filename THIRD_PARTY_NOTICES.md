# Third-party notices

BlogGPT's [Apache-2.0 license](LICENSE) covers the theme code. Third-party dependencies and assets retain their own licenses and notices. Documentation in `apps/docs/` has a separate [MIT license](apps/docs/LICENSE).

## Fonts and icon libraries

| Resource     | Use                                                                              | License / source                                                                          |
| ------------ | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Lucide       | Interface icons, distributed through `@iconify-json/lucide`                      | [ISC and upstream notices](https://github.com/lucide-icons/lucide/blob/main/LICENSE)      |
| Simple Icons | Social brand icons, distributed through `@iconify-json/simple-icons`             | [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)           |
| Noto Sans SC | Fonts for generated share covers, distributed through `@fontsource/noto-sans-sc` | [SIL Open Font License 1.1](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE) |

These packages include license metadata or license files. Other installed packages retain the licenses included with their distributions; `pnpm-lock.yaml` records the dependency versions.
